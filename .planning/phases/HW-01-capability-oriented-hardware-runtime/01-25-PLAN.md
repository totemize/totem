## Trust Boundaries

| Boundary | Description |
|---|---|
| rendered image → multipart bus | Screen-generated binary data crosses the HTTP parser and runtime. |
| bus health/events → presentation | Runtime-controlled values affect screen state and service readiness. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-01 | Tampering | frame upload | medium | mitigate | Validate dimensions/media/length/hash and require correlated successful result. |
| T-10-02 | Spoofing | bus endpoint | medium | mitigate | Default to loopback URL, use no remote fallback, and validate response type/ID. |
| T-10-03 | Denial of service | readiness loop | low | accept | Existing bounded timeout/poll interval is retained; service restart policy handles persistent absence. |
| T-10-04 | Information disclosure | screen diagnostics | low | mitigate | Display only stable status labels and never render secret/config/provider traceback values. |
</threat_model>
