| T-05-02 | Denial of service | uncooperative provider | critical | mitigate | Signal cancellation, test liveness after grace, contaminate, reject work, retain leases, and request controlled daemon restart. |
| T-05-03 | Tampering | direct Python call path | high | mitigate | Normalize/validate the same strict logical envelope and forbid carrier-only Python types. |
| T-05-04 | Repudiation | containment telemetry | medium | mitigate | Preserve mode, live invocation, cancellations, contamination, restart-required, and held-lease fields. |
</threat_model>
