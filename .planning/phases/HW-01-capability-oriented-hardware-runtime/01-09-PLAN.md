## Trust Boundaries

| Boundary | Description |
|---|---|
| supervisor → child executable | Untrusted provider code receives selected resources and configuration references. |
| child lifecycle → broker | Failure observations control release/reassignment of physical resources. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Elevation of privilege | worker spawn | high | mitigate | Pass only manifest-declared descriptors/resources, use no shell, preserve session-bound identity, document OS sandbox limitations. |
| T-04-02 | Tampering | stale child results | high | mitigate | Generation-bind pending IDs and discard every result/event from a dead generation. |
| T-04-03 | Denial of service | restart loop | high | mitigate | Fake-clock-tested bounded exponential backoff and quarantine after the configured failure window. |
| T-04-04 | Tampering / Safety | lease release | critical | mitigate | Require confirmed child exit and carrier closure before generation-scoped release/reassignment. |
| T-04-05 | Repudiation | lifecycle diagnostics | medium | mitigate | Emit ordered state/generation/exit/retry events with stable codes and no secret values. |
</threat_model>
