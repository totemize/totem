## Trust Boundaries

| Boundary | Description |
|---|---|
| byte stream → frame decoder | A provider can send arbitrary prefixes, lengths, JSON, and bytes. |
| decoded object → dispatcher | Untrusted logical values request capability work. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Denial of service | prefix/body decoder | high | mitigate | Reject version/codec/flags and enforce header/attachment/count bounds before allocation/read. |
| T-03-02 | Tampering | attachment table | high | mitigate | Enforce unique IDs, exact byte coverage, lengths, media types, and SHA-256 before dispatch. |
| T-03-03 | Spoofing | logical identity fields | high | mitigate | Do not accept provider identity from payload; routing context supplies session identity. |
| T-03-04 | Information disclosure | public errors | medium | mitigate | Map decode/dispatch failures to stable codes and keep tracebacks in supervisor-only logs. |
</threat_model>
